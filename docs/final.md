Order & Inventory Management API
A production-oriented backend service demonstrating real backend engineering challenges.

Proposed technology stack
Node.js 24 LTS
TypeScript
Express.js
PostgreSQL
Prisma ORM
Redis
BullMQ
Jest
Supertest
Docker
GitHub Actions


Features to implement
1. Core backend: User registration, login, roles, products, inventory and order management.
2. Database engineering: Relational schema, migrations, joins, indexing and transactions.
3. Concurrency: Prevent inventory overselling when multiple users place orders simultaneously.
4. API security: JWT authentication, role-based authorization, validation, rate limiting and secure error handling.
5. Caching: Redis caching, TTL, invalidation and cache consistency.
6. Background processing: BullMQ workers, retries, failure handling and idempotent jobs.
7. Integrations: Mock payment provider and secure webhook processing.
8. Testing: Unit, integration and concurrency tests.
9. Production practices: Docker, structured logging, health checks, graceful shutdown and CI.
10. Documentation: OpenAPI/Swagger, architecture diagram and meaningful README.
